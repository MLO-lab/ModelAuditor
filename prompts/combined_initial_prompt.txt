PART 1: METRICS SELECTION
========================

Select metrics based on the task type. Only use metrics listed below - these are the only ones available.

## CLASSIFICATION METRICS

Decision Logic:

IMPORTANT: You must ONLY select metrics that are compatible with the current task type.
- For CLASSIFICATION tasks: Select ONLY from specified "Classification Metrics".
- For SEGMENTATION tasks: Select ONLY from specified "Segmentation Metrics".
- For DETECTION tasks: Select ONLY from specified "Detection Metrics". DO NOT select classification metrics like Sensitivity or Accuracy, as they will cause runtime errors.

1. Metric options:
Classification Metrics:
- Accuracy - Overall accuracy
- BalancedAccuracy - Average recall per class
- Precision/Recall/F1 - Per-class or weighted average
- ConfusionMatrix - Full breakdown of errors

Segmentation Metrics:
- SegmentationIoU - Intersection over Union for segmentation masks
- SegmentationDice - Dice coefficient (F1 score) for segmentation
- SegmentationAccuracy - Pixel-wise accuracy

Detection Metrics:
- DetectionAP - Average Precision at IoU=0.50 (PASCAL VOC metric)
- DetectionAP50_95 - Mean Average Precision at IoU=0.50:0.05:0.95 (COCO metric)
- DetectionRecall - Recall at IoU=0.50
- DetectionPrecision - Precision at IoU=0.50
- DetectionF1 - F1 Score at IoU=0.50 problems: Sensitivity (recall), Specificity
- When preference for minimizing false positives: PositivePredictiveValue or FBetaScore (beta < 1)
- When preference for minimizing false negatives: NegativePredictiveValue or FBetaScore (beta > 1)
- When cost-benefit analysis is needed: NetBenefit

3. Multi-threshold Metrics:
- Default recommendation: AUROC
- When classes are highly imbalanced: AveragePrecision

4. Calibration Metrics:
- When calibration assessment is requested: ExpectedCalibrationError and RootBrierScore
- For comparison of calibration methods: KernelCalibrationError
- For overall probabilistic performance: NegativeLogLikelihood or BrierScore

Available classification metrics:
Sensitivity, Specificity, PositivePredictiveValue, NegativePredictiveValue, PositiveLikelihoodRatio, DiceSimilarityCoefficient, FBetaScore, NetBenefit, Accuracy, BalancedAccuracy, MatthewsCorrelationCoefficient, WeightedCohensKappa, ExpectedCost, AUROC, AveragePrecision, BrierScore, RootBrierScore, ExpectedCalibrationError, ClassWiseECE, ECEKernelDensity, KernelCalibrationError, NegativeLogLikelihood

For Multi-Label classification ONLY use:
MultiLabelSubsetAccuracy, MultiLabelHammingLoss, MultiLabelPrecision, MultiLabelRecall, MultiLabelF1Score, MultiLabelJaccardScore, MultiLabelAUROC

PART 2: DISTRIBUTION SHIFTS SELECTION
====================================

You'll also decide which distribution shifts should be used to test out-of-distribution robustness based on the deployment environment.

Available shifts (organized by category):

NOISE & ARTIFACTS:
- GaussianNoise([std_dev_values]) - e.g., [0.02, 0.05, 0.08]
- JPEGCompression([quality_values]) - e.g., [90, 75, 60] (lower=worse)
- MotionBlur([kernel_size_values]) - e.g., [3, 5] (odd integers)
- Pixelation([block_size_values]) - e.g., [2, 4, 8]

BRIGHTNESS & COLOR:
- BrightnessShift([jitter_values]) - e.g., [0.1, 0.2, 0.3] (range: [max(0,1-x), 1+x])
- ContrastShift([jitter_values]) - e.g., [0.1, 0.2, 0.3] (range: [max(0,1-x), 1+x])
- SaturationShift([jitter_values]) - e.g., [0.1, 0.2, 0.3] (range: [max(0,1-x), 1+x])
- HueShift([jitter_values]) - e.g., [0.02, 0.05, 0.1] (range: [-x, x], max 0.5)
- Grayscale([intensity_values]) - e.g., [0.3, 0.6, 1.0] (0=color, 1=gray)
- ColorJitter([magnitude_values]) - e.g., [0.05, 0.1, 0.15] (uses same ranges)
- Solarize([threshold_values]) - e.g., [0.9, 0.7, 0.5] (lower=more)
- Posterize([bits_values]) - e.g., [7, 5, 4] (integers, lower=more)

GEOMETRIC:
- Rotation([degrees_values]) - e.g., [5, 10, 15]
- HorizontalFlip (no parameters)
- VerticalFlip (no parameters)
- PerspectiveTransform([distortion_values]) - e.g., [0.02, 0.05, 0.1]
- ElasticTransform([alpha_values]) - e.g., [0.5, 1.0, 2.0]

BLUR & SHARPNESS:
- GaussianBlur([kernel_size_values]) - e.g., [3, 5, 7] (odd integers)
- Sharpness([factor_values]) - e.g., [0.7, 1.5, 2.0]

RESOLUTION & SCALE:
- ZoomIn([scale_values]) - e.g., [0.95, 0.85, 0.75] (lower=more zoom)
- ZoomOut([scale_values]) - e.g., [0.95, 0.85, 0.75] (lower=smaller)

OCCLUSION:
- RandomErasing([area_values]) - e.g., [0.05, 0.1, 0.2] (proportion)

Common Scenarios:
1. Medical Imaging: Focus on noise, brightness, contrast variations
   - Typical shifts: GaussianNoise, BrightnessShift, ContrastShift, GaussianBlur
2. Endoscopy/Colonoscopy: Lighting and quality variations
   - Typical shifts: BrightnessShift, ContrastShift, GaussianBlur, MotionBlur
3. Natural Images: Broader range of conditions
   - Typical shifts: GaussianNoise, BrightnessShift, Rotation, HorizontalFlip
